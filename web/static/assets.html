Taxa mínima de atratividade

Taxa mínima = a taxa real acima da inflação. Usada como taxa de desconto (VPL), custo de oportunidade e taxa da reserva.

Ativos

A alocação prioriza o ativo com maior retorno líquido anualizado (após imposto e taxas), respeitando os limites. Taxas e percentuais em %.

Como o valor líquido de cada ativo é calculado

Um pipeline genérico cobre todo tipo de investimento (calcular_valor_liquido em src/impostos.py):

  1. bruto = aporte_único(A) + série(P) — capitalização à taxa anual efetiva do ativo.
  2. ganho = bruto − (A + P × n) — só o ganho é tributado.
  3. imposto = alíquota × max(ganho, 0) — isento → 0, fixo → % fixa, prejuízos nunca são tributados.
  4. taxa — nenhuma → 0; aporte → % dos aportes; patrimonio → % a.a. geométrico ao longo do prazo; ganho → % do ganho.
  5. líquido = bruto − imposto − taxa; lucro = líquido − aportado.

Variáveis: A = aporte inicial, P = aporte mensal, n = prazo em meses. Após otimizar, o painel mostra este passo a passo com os números efetivos de cada ativo.
