Hurdle rate (minimum attractive rate)

Hurdle = the real rate over inflation. Used as the discount rate (NPV), the opportunity cost, and the reserve rate.

Assets

Allocation prioritizes the asset with the highest annualized net return (after tax and fees), honoring limits. Rates and percentages in %.

How the net value of each asset is calculated

One generic pipeline covers every investment type (compute_net_amount in src/tax.py):

  1. gross = lump_sum(A) + series(P) — compounding at the asset's effective annual rate.
  2. gain = gross − (A + P × n) — only the gain is taxed.
  3. tax = rate × max(gain, 0) — exempt → 0, fixed → flat %, losses are never taxed.
  4. fee — none → 0; contribution → % of deposits; assets → % p.a. geometric over the term; gain → % of the gain.
  5. net = gross − tax − fee; profit = net − contributed.

Variables: A = initial deposit, P = monthly deposit, n = term in months. After optimizing, the dashboard shows this walkthrough with the actual numbers of each asset.
